# GPVKR Catalog Bot

Telegram-бот для управления каталогом Android-игр проекта **«Геймпад в кармане»**.

Бот позволяет искать игры, получать ссылки на публикации, управлять каталогом и автоматизировать работу с игровым контентом.


## Возможности

- Поиск игр по названию с отображением подходящих результатов.
- Алфавитный каталог с удобной навигацией по буквам.
- Каталог по жанрам с возможностью просмотра игр каждой категории.
- Поддержка нескольких жанров для одной игры.
- Хранение игр и их версий в базе данных Cloudflare D1.
- Прямой переход к публикациям Telegram-канала.
- Автоматическое добавление новых игр при публикации в канале.
- Определение жанров по хештегам публикаций.
- Игнорирование служебных публикаций, не предназначенных для каталога.
- Добавление и удаление игр через административные команды.
- Массовый импорт игр и их версий из CSV-файлов.
- Синхронизация жанров ранее добавленных игр через пересылку публикаций.
- Ручное подтверждение или отклонение публикаций, требующих проверки.
- Система администраторов с разграничением прав доступа.
- Управление администраторами со стороны владельца бота.
- Редактирование текстов и элементов интерфейса непосредственно через Telegram.
- Настройка и обновление меню команд Telegram.
- Ограничение частоты поисковых запросов с возможностью изменения настроек.
- Поддержка отмены административных операций и выхода из режимов настройки.
- Работа на Cloudflare Workers без необходимости содержать собственный сервер.
- Хранение данных в облачной базе с сохранением каталога при обновлении кода.

## Технологии

| Технология | Назначение |
|------------|------------|
| JavaScript | Основной язык разработки |

| Cloudflare D1 | База данных |

## Архитектура

Проект построен на модульной архитектуре.

Cloudflare Worker принимает обновления от Telegram через webhook, обрабатывает команды и запросы пользователей и взаимодействует с базой данных Cloudflare D1.

Каталог, административные функции, работа с базой данных и управление текстами разделены на отдельные модули.

## Конфигурация

Для запуска требуется настроить Cloudflare Worker, базу данных D1 и переменные окружения:

| Переменная | Назначение |
|------------|------------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_ID` | Telegram ID владельца |
| `WEBHOOK_SECRET` | Секрет проверки webhook |
| `SETUP_KEY` | Ключ настройки |

Привязка базы данных осуществляется через `wrangler.toml` с именем `DB`.

**Не публикуйте реальные токены, пароли и секретные ключи в репозитории.**
